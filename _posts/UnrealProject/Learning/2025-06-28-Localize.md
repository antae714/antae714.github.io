## **FText**
언리얼 문자열에는 여러 목적의 문자열 타입이 있습니다.  
- `FString`: 일반 문자열, 현지화 미지원  
- `FName`: 고유 식별자, 현지화 미지원  
- `FText`: UI 표시용, 현지화 지원

## **C++: LOCTEXT 사용 예**
`FText`를 cpp에서 사용하려면 `LOCTEXT` 매크로를 사용합니다.
```cpp
	// LOCTEXT 에 사용할 네임스페이스 정의
	// 단일 파일 안에서만 유효하며, 파일이 끝나기 전 정의해야 합니다.
	#define LOCTEXT_NAMESPACE "MyNamespace"
	// 텍스트 리터럴을 생성합니다.
	constFTextHelloWorld= NSLOCTEXT("MyOtherNamespace","HelloWorld","Hello World!")
	constFTextGoodbyeWorld= LOCTEXT("GoodbyeWorld","Goodbye World!")
	// 파일이 끝나기 전 네임스페이스 정의를 해제합니다.
	#undef LOCTEXT_NAMESPACE
```

## **FText 구조 (Namespace / Key / Value)**
FText는 **Namespace, Key, Value**로 구성되며
**Namespace + Key**로 현지화된 텍스트를 조회합니다.

## **String Table 권장**
코드에서 `LOCTEXT` 사용이 많아지면 수집·관리가 번거롭습니다.
가능하면 블루프린트의 **String Table**로 한곳에서 관리하는 것을 권장합니다.
블루프린트에서 만든 String Table은 `FText::FromStringTable`로 접근합니다.

## **현지화 대시보드 워크플로**
**현지화 대시보드**에서 에셋/코드를 스캔해 텍스트를 수집하고,
PO 파일로 내보내거나 에디터에서 직접 번역할 수 있습니다.
적용된 텍스트는 컴파일 과정을 거쳐 게임에 포함됩니다.
